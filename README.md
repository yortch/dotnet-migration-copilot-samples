# DotNet Migration Copilot Samples

## Samples:

- [ContosoUniversity](https://github.com/Azure-Samples/dotnet-migration-copilot-samples/tree/main/ContosoUniversity): This university management sample now targets .NET 10 with ASP.NET Core MVC, SQL Server, Windows Negotiate authentication, database-backed notifications, and local teaching-material uploads. Its future cloud migration target is Azure Container Apps with Azure SQL Database, Azure Service Bus, and Azure Blob Storage.
