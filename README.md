# DotNet Migration Copilot Samples

## Samples:

- [ContosoUniversity](https://github.com/Azure-Samples/dotnet-migration-copilot-samples/tree/main/ContosoUniversity): A university management application migrated from ASP.NET MVC 5 on .NET Framework to ASP.NET Core MVC on .NET 10. It currently uses SQL Server for data, process-local notifications, and local file storage; Azure hosting and cloud services are not configured by this sample.
